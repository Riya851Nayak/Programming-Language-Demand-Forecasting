# Programming Language Demand Forecasting

## 📌 Project Overview

This Machine Learning project analyzes historical programming language demand trends from **2020 to 2026** and predicts the future demand of programming languages up to **2036**.

The project uses **Linear Regression** to identify trends and generate future demand forecasts.

## 🎯 Objectives

* Analyze programming language demand trends.
* Compare the growth of different programming languages.
* Predict programming language demand up to 2036.
* Calculate growth percentage and absolute growth.
* Evaluate model performance using **MAE** and **R² Score**.
* Identify the fastest-growing programming language.

## 💻 Programming Languages Analyzed

* Python
* Go
* SQL
* Rust
* JavaScript

## 🛠️ Technologies Used

* Pandas

## 📊 Machine Learning Model

The project uses:

**Linear Regression**

The model learns historical demand trends and predicts future programming language demand.

## 📈 Model Evaluation

The following metrics were used:

### MAE (Mean Absolute Error)

MAE measures the average prediction error.

**Lower MAE = Better prediction accuracy**

### R² Score

R² measures how well the model explains the data.

**Higher R² = Better model performance**

## 🚀 Key Results

According to the analysis:

* **Go** showed the highest predicted growth percentage.
* **SQL** showed strong future growth.
* **Rust** also demonstrated significant growth.
* **Python** had the lowest prediction error (MAE).
* Go achieved the highest R² score among the analyzed languages.

## 📊 Future Predictions

The model predicts programming language demand from **2027 to 2036** based on historical trends.

The predictions should be considered estimates because future technology trends can change due to:

* AI development
* Industry requirements
* New technologies
* Developer preferences
* Job market trends
